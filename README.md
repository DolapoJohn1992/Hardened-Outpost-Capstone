# Hardened Outpost Capstone: Vulnerability Assessment & Exploitation

## Project Overview
This project serves as a comprehensive demonstration of vulnerability assessment, network discovery, and exploitation techniques within a virtualized Linux environment.

## Technical Stack
* **Operating System:** Ubuntu Linux
* **Tools:** Metasploit Framework (MSF), Nmap, Bash
* **Environment:** VirtualBox, VS Code, Git/GitHub

## Project Phases
1. **Network Interface Discovery**: Identified local network configuration (LHOST: 10.0.2.15).
2. **Vulnerability Research**: Audited MS17-010 (EternalBlue) protocols.
3. **Exploitation Proof**: Established reverse shell sessions and verified system-level access using whoami and sysinfo.

## Portfolio Artifacts
The repository includes terminal logs and verification screenshots of successful command execution.
